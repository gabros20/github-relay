# github-relay

"Research GitHub, not read GitHub." A single-user, zero-paid-API, LLM-free Bun/TypeScript CLI
(`ghrelay`) + thin MCP shim (`github-relay-mcp`) + auto-generated Claude skill that turns
natural-language intent into a ranked, explainable, star-skeptical shortlist of repos, then
deep-reads only the finalists. See [`PLAN.md`](./PLAN.md) and [`docs/DESIGN-v1.0.md`](./docs/DESIGN-v1.0.md)
for the full design.

**Status: under construction.** This is the v0.1 scaffold — command adapters, scoring, and the
generated skill content ship in later tasks.
